# 🎯 Exam Preparation Command Center (Target: 16 November)

A responsive, local-first exam preparation dashboard designed specifically for your 4 core subjects:
- **PSNM** (Probability, Statistics & Numerical Methods)
- **Signals and System**
- **Digital Circuit Design (DCD)**
- **EDC** (Electronic Devices and Circuits)

---

## 🚀 Features

1. **Target Countdown to 16 November**:
   - Real-time countdown clock (days, hours, minutes, seconds).
2. **Subject Navigation**:
   - Switch between **PSNM**, **Signals and System**, **DCD**, and **EDC** with one click.
   - Live completion badges showing percentage progress for each subject.
3. **Dual Counter Progress for Every Topic**:
   - **Lecture Counter**: Increment/decrement or directly edit completed lectures vs. target total.
   - **Topic-wise Problem Counter**: Increment/decrement solved problem count with visual progress bars.
4. **Editable Notes & Progression Log**:
   - Built-in note area for every topic to record formulas, problem numbers solved (e.g. *Ch 3 Q1-Q15*), tricky edge cases, and doubts. Auto-saved locally.
5. **Topic Management**:
   - Add new custom topics and chapters with specific lecture and problem targets.
   - Delete or update topic status (`Not Started`, `In Progress`, `Revision Needed`, `Completed`).
6. **Data Persistence & Portability**:
   - Saves progress automatically in your browser's `localStorage`.
   - **Export & Import (JSON)** buttons at the top to back up or sync progress across devices.
